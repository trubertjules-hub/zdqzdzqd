# Dossier images

Dépose ici les vraies photos produits, avec exactement ces noms de fichiers
(ils sont déjà référencés dans `services.html` et dans le panier Snipcart) :

- `porte-cles.jpg` — porte-clés collector
- `mug.jpg` — mug édition fan
- `tshirt.jpg` — t-shirt hommage

Formats recommandés : JPG ou WebP, environ 1000×1000px, fond neutre ou
lifestyle, poids < 300 Ko par image pour ne pas ralentir le site.

Tant que ces fichiers ne sont pas présents, les images ne s'affichent pas
dans le panier Snipcart (le site reste fonctionnel, juste sans visuel produit
côté panier — les blocs "Photo : ..." sur les pages restent des placeholders
en CSS, à remplacer directement dans le HTML par des balises `<img>` une fois
les photos prêtes).
